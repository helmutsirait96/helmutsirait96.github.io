## 📄 About Project
This website is my personal portfolio, designed to showcase my profile, skills, and the best projects I've worked on. It's built with a mobile-first design approach to ensure an optimal user experience across all devices.

### ✨ Key Features:
*   **Responsive Layout:** Adaptive display from smartphone screen to desktop.
*   **Dynamic Project Gallery:** Using DOM manipulation to filter projects by category.
*   **Custom Form Validation:** Client-side validation on contact forms to ensure data is filled in correctly before submission.
*   **Dark/Light Mode:** Theme switching feature
*   **Micro-interactions & Animations:** Smooth animation implementation using native CSS/JS as well as libraries like GSAP, mixitup


## 🛠️ Tech Stack
*   **Languages:** HTML5, CSS3, JavaScript (ES6+)
*   **Styling:** CSS Native
*   **Interactivity:** Vanilla JavaScript, GSAP,  mixitup  
*   **Deployment:** Github Pages
